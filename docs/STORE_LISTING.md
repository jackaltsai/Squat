## 完整說明（Full description，上限 4000 字元）

```
深蹲教練是一款使用手機相機即時分析深蹲動作的健身輔助 App。不需要穿戴裝置，
只要架好手機、退後幾步入鏡，就能自動計算深蹲次數，並依你個人的身體條件
給予深度與姿勢回饋。

【核心功能】

✓ 自動計次
系統會即時追蹤你的髖、膝、踝關鍵點，透過穩定的動作辨識邏輯，
自動判斷「下蹲到底、起身回到站姿」的完整動作並計次，
不受一般站立晃動影響，避免誤判。

✓ 個人化深度校正
每個人的柔軟度、身高、骨架比例不同，本 App 會先引導你完成
站姿校正與基準深蹲校正，建立屬於你的個人化深蹲深度基準，
而不是套用一套死板的標準。

✓ 三段式即時回饋
訓練時依照你的深度達成率，即時顯示綠／黃／紅三色回饋，
一眼就知道這一下蹲得夠不夠深。並可依訓練目標選擇
「入門」「一般」「進階」三種難度模式。

✓ 膝內夾提醒
深蹲最容易出現的姿勢問題之一就是膝蓋內夾，本 App 會在動作
最低點自動判斷膝蓋是否明顯內夾，並透過語音即時提醒，
幫助你維持正確的膝蓋方向，降低受傷風險。

✓ 語音教練提示
訓練中不需要一直盯著手機，語音提示會在需要時提醒你
「蹲深一點」或「膝蓋往外一點」，讓你可以專注在動作本身。

✓ 訓練歷程紀錄
每次訓練的次數、深度達標比例、膝內夾比例都會自動保存，
方便你追蹤自己的進步。所有資料僅儲存在你的裝置本機，
不會上傳雲端。

【隱私保護】
本 App 的所有姿勢辨識運算皆在裝置本機完成，相機影像不會
被儲存、錄影或上傳至任何伺服器，僅用於即時動作分析。

【適合對象】
- 想在家自主訓練，但不確定深蹲深度/姿勢是否正確的使用者
- 想有一個自動計次工具，減少數數分心的重訓愛好者
- 教練/自主訓練者想快速記錄每次訓練的深度與姿勢品質

【重要提醒】
本 App 提供之動作分析僅供健身參考，非醫療器材，不構成醫療建議。
若有特殊身體狀況，請於運動前諮詢專業醫療人員或教練。
```
